# Alfulaiti Development — Growth Intelligence v3

A locally runnable marketing and growth intelligence workspace tailored to a real-estate development team. Includes social analytics, campaign management, lead funnel metrics, source attribution, quality-stage tracking, rule-based growth signals, on-demand weekly summaries, editable values and CSV exports. Starter values are illustrative and must be replaced with verified company data before using them for management reporting.

## Windows
1. Extract the ZIP.
2. Double-click `START_WINDOWS.bat`.
3. Dashboard: http://127.0.0.1:8000/
4. API documentation (optional): http://127.0.0.1:8000/docs

First launch needs internet to install Python packages and load Chart.js / Google Fonts. Dashboard data is stored in this browser's local storage. No social accounts need to be connected.


## Portfolio-safe positioning
This is a local analytics prototype. It does not connect to live Meta, Google, CRM or sales systems. Data is editable and stored in the browser on this computer. Integrations can be added later through official APIs and approved credentials.


## Attribution & automation layer (v3)
- Lead attribution register with source, campaign, project, stage, quality, date and estimated opportunity value.
- Source-level qualification rate comparison and cost-per-qualified-lead estimate.
- Rule-based growth signals and an on-demand weekly summary download.
- This is not a background scheduler or live integration. Reports are generated when a user clicks the button; data remains in browser local storage.
- Use anonymized records only until approved security and CRM integration controls are implemented.
